# Before the Walls Change

A photo essay by Panta Rhei Productions about Lafayette’s old Trappey cannery.

## Publish on GitHub Pages

1. Extract the ZIP. Create a public GitHub repository named `before-the-walls-change`.
2. In the repository, choose **Add file → Upload files**. Upload the extracted
   contents to the top level so `index.html` sits next to the `assets` folder.
   Keep the folder structure intact and include `.nojekyll`. Commit to `main`.
3. Open **Settings → Pages**. Under **Source**, select **Deploy from a branch**.
   Select **main** and **/(root)**, then click **Save**.
4. When deployment finishes, open **Settings → Pages → Visit site** and copy
   that address into your email. With the repository name above, the address
   will look like `https://YOUR-USERNAME.github.io/before-the-walls-change/`.

[GitHub Pages setup documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
